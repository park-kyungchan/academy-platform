# Draft S08 V3 admission proposal — independent decision pending

This document does not accept a new boundary or change the frozen source expectations. It specifies the current candidate adapter precisely so Lead/Wonder can accept it for the retained selected pure domain, request a new independently frozen extension, or keep S08 held. All 202 selected cases are intended to retain their original full source frames. No unsupported case is removed from comparison.

1. Non-learning recursion: admission canonicalJson (`dailyrecord-save-admission.ts:72–79`) recurses with no cycle/depth guard; CISM cismHash (`cismWeeklyProtocol.ts:5`) delegates to the runtime stringifier. The source corpus deliberately does not execute their cycles/unbounded depth. Proposal: admit only acyclic descriptors/JSON up to 64 recursive levels for those two families, with status64 `s08_semantic_admission_required` before invocation outside that domain. Learning's original depth>64 and cycle errors remain source throws. The new bound is an adapter proposal, not a claimed source refusal or approved universal source transition. Any broader runtime-specific RangeError/TypeError behavior needs a new versioned source corpus and independent review; frozen202 is unchanged.
2. Explicit descriptors: support the exact baseline constructors (undefined, binary64 -0/NaN/Infinity, bigint1, synthetic function/symbol, sparse2/decorated1, ISO Date, null prototype, own symbol, constant getter, self-cycle, depth64/65). No arbitrary getter, prototype method, proxy, toJSON function, shared-object identity or JS execution is accepted. Date's selected toJSON bytes and getter read events are preserved. Broader exports/constructors require new source characterization, not dropping them to ordinary JSON.
3. Schema boundary: review accepts source-valid, strict context/proposals/observation shapes with schema field ordering/default origin, except missing observation fields are admitted to reproduce the characterized original Zod read-failure diagnostic. Other schema-invalid shapes are explicit adapter refusals, not fabricated Zod/source exceptions. UTC instants with either no fractional part or exactly three fractional digits are admitted for the test clock/observations; source-supported offsets and 1–2 fractional digits need a versioned extension before acceptance. General schema-error closure remains an S08 pure-source obligation if Lead includes it; it is not falsely assigned to S09. Null/undefined objects at uncharacterized Object.keys exception sites also return adapter admission. Production caller validation is not supplied by this finite comparison adapter.
4. Wire bounds: at most 1048576 bytes, 65536 nodes, 65536 decoded node visits, depth96; duplicate ordinary member keys/cyclic flat references rejected. These bounds protect decoding independently of the domain encoder. They do not alter the original business strings/known blank/zero/null/missing/array holes. Source output frames must fit the explicit finite encoder domain.
5. No test-provider production default: review requires explicit UUID/clock ports before constructing intake or digest. Synthetic policy flags, synthetic pins and local fake action callbacks are comparison composition only. Actual policy/namespace/authentication/approval is a later integration obligation, not an admission decision inferred here.
