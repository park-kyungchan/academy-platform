## Clocks, durations and lifecycle

Both source freshness checks accept inclusive ages 0..300000ms. No exact source
read-completion or evaluation timestamp is exposed. Samples are named request
send/response receive brackets. Source timestamps must equal independent actual
producer bytes. Conservative wall intervals round outward to source Date's
integer millisecond precision. A fresh-generation causal proof can establish
normal success within that measured envelope; otherwise a boundary-straddling
interval is UNQUALIFIED. A source accepting at +300000 followed by receive at
+300001 must not be labelled semantically stale from receive time alone.

Nondecreasing stable local wall time between samples is an explicit assumption.
Wall/monotonic disagreement, backwards time or unsupported/ambiguous domains
withhold qualification. Samples cannot exclude an arbitrarily short hidden
clock step. Internal service/bridge evaluations are never fabricated. Separate
Date.now calls can yield equal receipt/meta elapsed values. Each has its own
integer role and enclosing span; equality is allowed, reverse source order is
refused under the stated clock assumption. Elapsed values are never replaced by
old minimum constants. Process lifetime and per-request windows are distinct.

Recorder deadlines include setup, controlled waiting, cleanup, reap and drain.
The 85s cleanup reserve precedes the 90s mode ceiling. CPU90 is inherited
**per process**, not a tree-aggregate CPU quota. Files <=64MiB, each raw channel
and combined top output <=12MiB. No expensive build slot is used. SIGTERM goes
only to the owned recorded process group; actual readbacks must show it gone.
Failed/late cleanup is retained and unqualified, never rewritten as within budget.

Bounds requires actual hung source handler proof, unknown/no-retry, native -15
and empty group readback, then separately recorded fictional nonblocking flock
and native true exec/exit0. Missing JS EXIT is legitimate only with native
terminal evidence; flock has no Bun/JS EXIT requirement. Outer zero cannot hide
