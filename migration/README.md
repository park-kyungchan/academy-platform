# Historical migration records

Current fixture and participant ownership is documented in
[docs/fixture-ownership.md](../docs/fixture-ownership.md). Its historical-reproduction
and recovery section supersedes commands and source-locator availability claims
in all nested migration READMEs, scripts, contracts, manifests and frozen records.
These retained records describe completed allocations and preserve their original
bytes; they are not current package scripts, CI checks or installed entrypoints.
Reproduce them only from their complete pinned revision in an isolated checkout.
Current Cargo tests remain enabled and read the crate-owned fixture copies.
