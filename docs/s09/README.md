`edu-academy-sources` is an explicit offline domain crate. Its named executable is
`edu-academy-sources-offline`. Each stdin JSON line requests an operation; each stdout
line is an observed return or error. `inventory` reports its actual selected operations.
There is no network transport implementation, default evidence root, TypeScript
interpreter, reference import, expected-result lookup, account lock or Ontology store.

## Strict owner root and unadmitted content

The legacy saved loader deliberately preserves permissive parent-symlink and mode
behavior. `owner_root.rs` is a separate admission boundary with distinct errors:
explicit canonical absolute root, OS effective UID, trusted root/owner ancestors,
owner-private root/descendant directories, regular private single-link leaves,
no-follow descriptor-relative walks, pinned path/descriptor identities, no descendant
device crossing and bounded same-descriptor capture/hash/parse. Manifest cap is4MiB;
saved leaf cap is32MiB. Legacy pinned-local cap remains4MiB.

A bounded same-descriptor reread detects the controlled same-size in-place race in the
qualification tests. It does not make malicious same-UID mutation safe or establish
cross-file atomicity. The owner must publish stable immutable bytes. Actual native
UID/root launch and an adversarial mounted descendant have not been exercised.

`evidence.rs` projects only `UNADMITTED` data. It carries explicit existing-owner account
association as untrusted evidence, account/instance namespace, unchanged legacy identity,
predecode bytes/hashes, coherent captured-file manifest, exact raw UTF-16 controls and
selectors/physical tuple. Fields are recomputed from the captured Main document and
independently matched selected XML, never accepted from caller-declared projected fields.
JSON projections likewise resolve captured JSON pointers. No Policy, Grant, Session,
trusted binding, Admission, Append, native key insertion or S10 journal change occurs.
Fictional account labels are not credentials or actual owner association proof.
