Read the module README and the relevant retained source before changing behavior. The old standalone UI, integration harness and CI records are retired; do not recreate their gates, registries or native contracts.

Preserve tools/academy-mcp and every retained dependency with an actual source, Rust or host consumer. Keep pinned artifacts and historical source records immutable.
