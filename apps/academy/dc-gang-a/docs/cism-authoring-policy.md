# CISM weekly authoring policy

Scope: internal weekly CISM reports submitted to the deputy director. User-confirmed2026-11-02. This is separate from parent-facing DailyRecord policy and does not change it. PDF generation remains a user action.

Use a deliberate mix of concise report-style endings for facts/status and polite complete sentences for interpretation, guidance or requests. The user selected mixed style by field. Keep the same style within a short paragraph; do not alternate mechanically.

- State the relevant student, dated occurrence and exact book/unit/activity when necessary for the deputy director's decision. Keep solved, graded, corrected, teacher-reviewed and entered in the app separate.
- Use short factual bullets for completed work, observed difficulty and next checks. Example with invented content: `A학생: 분수 나눗셈 오답수정 완료 확인. 다음 수업에서 계산 과정 재점검 예정.`
- Use polite prose when explaining a concern, guidance or a requested coordination. Example: `계산 과정의 생략이 반복되어 풀이노트 점검을 강화하겠습니다.` This example is not evidence about any real student.
- Praise observable effort or progress with evidence. Describe a difficulty as a learning observation with the intervention and follow-up; do not label the student's character or invent an internal state.
- Use the corresponding Sunday–Saturday DailyRecord and student records. Distinguish the date of an activity from the date a later teacher correction was reported. Do not move current progress backward into an earlier week.
- Do not infer numeric note percentages, weekly test scores or class atmosphere from isolated scores, task counts or missing entries. Source-computed values remain source values. Interview only missing teacher judgments; do not ask already settled questions.
- For a missing record, state the precise evidence limit in ordinary teaching terms. Do not convert an empty record into `없음`, `미완료`, zero or a claimed counseling event. A verified `해당 없음` is a teacher fact; lack of evidence is different.
- Keep parent greetings, home-support requests and promotional reassurance out of this internal report. Include only consultation details needed for teaching/coordination; do not copy unrelated private family narratives.
- Preserve existing saved CISM content and original before-values. Review exact additions and explicitly requested incomplete-narrative completions, save only those supported changes and read back the result. Keep existing numeric values; new unrecorded atmosphere/note percentages are teacher-review proposals, never observed measurements. Parent sending, PDF/report generation and printing are separate effects.
