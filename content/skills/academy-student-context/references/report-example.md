# Synthetic reporting example

This fictional example illustrates structure and reconciliation only. It is not a roster, a current student record, or an academy-wide assessment policy. Bracketed fields must be grounded before use; omit irrelevant fields rather than outputting placeholders.

```text
[YYYY-MM-DD 학원 수업 맥락 / 1부 학생A]

1. 학생A
  1.1 당일 흐름
    - 15:00 출석, 기존 숙제 확인 완료: 당일 교사 보고.
    - 개념백지테스트 진행 → 16:10 교사 완료 확정.
    - 교재A 4-3 오답클리닉은 진행중 보고 후 당일 교사완료로 갱신.
    - 기존 84점 총괄평가와 당일 재도전 프린트의 동일 회차 여부는 미확인.

  1.2 교재A / 초5-1 2권 / 현재 교재
    - 아래 점수는 과거 필수예제·유형다지기 순서의 응시 점수.

    4-1 분수의 기본 성질: 과거 80/90.
      - 이전 수업의 오답·유사클리닉 교사완료 유지.
      - 별도 DT 회차별 최종판정은 미확인.
    4-2 약분:
      - 보강일 DT 2회 완료 보고는 해당 보강일 이력으로 보존.
      - 개별 회차의 재오답 확인 범위는 미명시.
    4-3 통분:
      - 당일 별도 오답클리닉 교사완료.
      - 교재 내부 오답, 별도 유사클리닉 판정으로 확대하지 않음.
    4-4 분수의 크기 비교:
      - 과거 숙제 미수행 → 당일 숙제 채점 완료 보고로 갱신.
      - 별도 DT·클리닉 최종판정은 미확인.
    4-5 분수와 소수의 크기 비교:
      - 이번 숙제에서 4-4로 대체됨. 현재 미제출로 집계하지 않음.
    4 대단원총괄평가:
      - 기존 84점 응시와 당일 재도전 완료 보고를 별도 유지.
      - 동일 실물·회차 연결과 후속 오답 판정은 미확인.
    5-1~5-4 및 5총괄:
      - 후속 목차. 배정·수행 근거 미확인으로 미이행 과제에 포함하지 않음.

  1.3 교재B / 초5-2 2권 / 이전 교재
    4-3 소수의 곱셈:
      - 현재 교재A의 4-3 통분과 별도 단원.
      - 과거 오답클리닉 완료와 새 DT 숙제를 구분.
      - 새 숙제: DT 기본 1회·발전 1회, 총 2회.
    4-4 소수의 곱셈 활용:
      - 활동별 최종판정 미확인.

  1.4 새 숙제·지도 방향
    - 최종 새 숙제: 교재B 4-3 DT 기본·발전, 총 2회.
    - 최초 계획했던 별도 유사클리닉은 교사 결정으로 제외.
    - 제출기한은 미명시. 지도계획 종료일을 제출기한으로 바꾸지 않음.
    - 오늘 확인: 총괄 재도전의 회차 연결 및 후속 오답 확인 여부.
    - 제안: 해당 확인 후 남은 오답만 지도. 추가 숙제 배정으로 기록하지 않음.
```

For a one-unit update, keep the same title and student numbering, then include only `당일 변경`, the affected book/unit, and any changed active homework. For a full class report, repeat the complete student structure; do not merge students into common score or task totals without explaining the counting scope.
